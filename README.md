# LinkOra 🎓

A **verified university network platform** connecting students, alumni, mentors, and institutions — built for Hack the future 3.0 2026.

## 🌟 Features

- 🔐 Multi-role authentication (Student / Alumni / Teacher / Admin)
- 📧 Email OTP verification
- 👤 Rich profile management with file uploads
- 🤝 Connection requests between students & alumni
- 🎯 1-on-1 Mentorship system with feedback
- 💬 Real-time chat with 5-minute free sessions
- 🤖 AI-powered mentor matchmaking
- 📄 AI resume analyser
- 🛡️ Admin dashboard with verification & analytics
